# 原子套利与 CEX–DEX 对冲交易系统
## 风控参数基线与熔断规则（v1.0）

**状态：待确认**  
**审计资金基准：5,000 USDC 等值**  
**参数性质：保守初始值，须在历史审计及 Paper Trading 后校准**  
**适用：DEX 原子套利、CEX–DEX 现货对冲**

---

## 1. 风控总原则

1. 风控必须在后端执行，不能仅依赖前端按钮。
2. 硬风控不允许通过策略参数关闭。
3. 所有风控判断都要记录原因、参数版本和数据时间。
4. 数据不完整或未知时默认拒绝交易。
5. 不允许用理论毛利润代替净利润。
6. 不允许使用过期的池状态或盘口数据生成有效交易计划。
7. 不允许把 CEX 订单请求成功当成实际成交。
8. 任何实际成交数量都必须与另一条腿重新匹配。
9. DEX 失败的 Gas 成本必须记录。
10. CEX–DEX 未对冲敞口必须单独计量。
11. 所有熔断必须有明确范围和恢复条件。
12. 风控参数必须支持版本控制和审计。

## 2. 参数等级

- **HARD STOP**：硬性拒绝或暂停，不允许绕过。
- **SOFT BLOCK**：当前机会拒绝，系统可继续扫描其他机会。
- **WARNING**：预警，保留观察但不能自动突破硬限制。
- **PAPER ONLY**：仅作为模拟环境评估参数，不能直接作为实盘准入值。

## 3. 全局资金风险

| 参数 | 初始值 | 处理方式 |
|---|---:|---|
| 审计资金基准 | 5,000 USDC | 所有收益、损失和回撤按实际权益计算 |
| 单笔模拟研究规模 | 250–10,000 USDC | 分档测试，不代表实盘额度 |
| 第一阶段未来实盘候选单笔上限 | 账户净值 5%，即 250 USDC | HARD STOP，需后续审批开放 |
| 单 Token 合并敞口上限 | 账户净值 10%，即 500 USDC | HARD STOP |
| 单一场所资金使用率 | 80% | 必须保留至少 20% 资金缓冲 |
| 全局日亏损上限 | 账户净值 1%，即 50 USDC | HARD STOP，全局暂停 |
| 单策略日亏损上限 | 账户净值 0.5%，即 25 USDC | HARD STOP，暂停对应策略 |
| 最大权益回撤 | 账户净值 5%，即 250 USDC | HARD STOP，暂停所有策略并重新评估 |
| 同一链待确认交易 | 初期每个执行账户最多 1 笔 | 防止 Nonce 和资金状态冲突 |
| 单一 Token 最低库存 | 按计划所需数量及安全缓冲计算 | 不足则拒绝机会 |

说明：

- 日亏损统计应包括已实现损失、可计量未实现损失和已发生交易费用。
- 最大回撤以历史权益峰值到当前权益计算。
- Paper 账户与未来 Live 账户独立计算。
- 多策略之间不能通过账本转移掩盖真实损失。
- 未来实盘 250 USDC 单笔上限只是首轮小额候选值，需通过审计和 Paper 验收后再确认。

## 4. 收益与成本门槛

### 4.1 DEX–DEX 原子套利

| 参数 | 初始值 | 处理方式 |
|---|---:|---|
| 最低净利润 | `max(2 USDC, 交易名义金额 × 10 bps)` | 不满足则拒绝 |
| Gas / 毛利润占比 | 不超过 25% | HARD STOP |
| 绝对 Gas 费用上限 | 初始候选 5 USDC | 按链单独校准 |
| 单路线最大交易跳数 | 4 跳 | 超过需额外验证 |
| 单腿最低输出 | 必须显式指定 | 缺失即拒绝 |
| 最终资产 | 必须回到起始 Token | 不闭环即拒绝 |
| 闪电贷费用 | 读取当前实际费用 | 不允许硬编码为固定收益成本 |
| 预估利润安全折扣 | 至少测试 50% 保守折扣场景 | 不将理论利润直接用于验收 |

DEX 交易净利润应至少扣除：

- DEX Pool Fee。
- Gas。
- Priority Fee / Builder 支付（如适用）。
- Flash Loan Fee。
- 模拟滑点。
- 抢先交易和夹击风险准备金。
- 其他确定性执行费用。

### 4.2 CEX–DEX 对冲套利

| 参数 | 初始值 | 处理方式 |
|---|---:|---|
| 最低保守净利润 | `max(5 USDC, 交易名义金额 × 30 bps)` | 不满足则拒绝 |
| CEX 深度要求 | 允许价格区间内可见深度至少为订单金额的 10 倍 | 超过 10% 深度占用则拒绝或缩量 |
| CEX 买卖保护价格 | 距参考 Bid/Ask 不超过 10 bps | 超出则不下模拟订单 |
| DEX 价格冲击 | 全路线初始上限 20 bps | 超过则拒绝 |
| CEX 手续费 | 使用交易所真实费率表 | 费率未知则拒绝 |
| DEX Gas 费用 | 必须计入 | 不得忽略 |
| 库存再平衡成本 | 单独计入 | 不得隐藏或设为零 |
| 延迟风险准备金 | 必须扣减 | 依据历史延迟分布校准 |
| 对冲补偿成本 | 必须建模 | 不得假设补偿总能按原价成交 |
| 预估收益安全折扣 | 必须测试 50% 保守折扣场景 | 作为压力分析，不作为盈利保证 |

CEX–DEX 净利润计算：

`保守净利润 = DEX 回款价值 + CEX 回款价值 - 两边投入价值 - DEX 手续费 - CEX 手续费 - Gas - 价格冲击 - 延迟风险准备金 - 补偿成本 - 库存再平衡成本`

CEX 现货对冲的预置库存不计为利润。不同场所的资产余额变化必须在各自账本中记载。

## 5. DEX 数据与执行风控

| 参数 | 初始值 | 触发处理 |
|---|---:|---|
| 模拟使用的区块状态 | 当前已确认可读的最新状态 | 使用过期状态拒绝交易 |
| 报价区块差 | 不超过 1 个区块 | HARD STOP |
| 报价最大时间 | `min(2 × 链平均区块时间, 3 秒)` | 超时重新报价 |
| RPC 节点数量 | 主节点 + 备用节点 | 不能只依赖单点 |
| RPC 区块差异 | 超过 1 个区块或 Hash 不一致 | 暂停该链扫描 |
| RPC P95 延迟 | 初始预警 500 ms，硬性阈值 1,000 ms | 超限降级或暂停 |
| 连续 RPC 失败 | 3 次 | 暂停该链 |
| Pool 状态不一致 | 立即拒绝 | 重新读取并重算 |
| 单腿最低输出 | 必须符合模拟结果和安全滑点 | 不满足整笔回滚 |
| Token Code Hash 变化 | 立即暂停受影响 Token | 重新验证 |
| Pool / Router 代码或版本变化 | 立即暂停相关适配器 | 重新验证 |
| 未验证 Token | 禁止自动执行 | 仅观察或人工研究 |
| Fee-on-Transfer Token | 默认禁止 | 独立适配后另行评估 |
| 交易计划有效期 | 初始不超过 30 秒且受区块约束 | 过期拒绝 |

不同链的区块时间、RPC 延迟和 Gas 特征差异较大，不能把单一链的参数不经校准复制到所有 EVM 网络。

## 6. CEX 市场数据风控

| 参数 | 初始值 | 触发处理 |
|---|---:|---|
| 实时盘口最大年龄 | 250 ms | 超时拒绝新机会 |
| 盘口 Snapshot | 启动时必须成功取得 | 不完整则禁止扫描该交易对 |
| 盘口 Sequence Gap | 任何未修复缺口 | 标记 INVALID 并重新同步 |
| WebSocket 断线 | 立即标记盘口失效 | 重连并获取新 Snapshot |
| 本机与交易所时间差 | 初始预警 250 ms | 超限校时或暂停 |
| 盘口深度占用 | 不超过允许区间内可见深度的 10% | 超过则缩量或拒绝 |
| CEX 费率缺失 | 不允许生成可执行机会 | 重新同步费率 |
| 交易规则不完整 | 不允许提交 Paper 订单 | 更新 Instrument Rules |
| 交易所维护状态 | 立即停止对应市场扫描 | 恢复后重新验证 |
| 数据乱序 | 不允许继续消费 | 重新同步 |
| API 速率余量 | 保留至少 30% | 接近限流时降低请求频率 |

CEX 盘口、费用、最小数量、最小名义价值、数量精度和价格精度必须使用交易所对应交易对的实际规则。

## 7. CEX–DEX 双腿对冲风控

| 参数 | 初始值 | 触发处理 |
|---|---:|---|
| 未对冲敞口上限 | 账户净值 0.5%，即 25 USDC | HARD STOP，触发补偿 |
| 最大未对冲时间 | 2 秒 | 超时触发补偿并暂停对应交易对 |
| 对冲完成时限 | 第一条腿完成后 2 秒 | 超时执行风险处理 |
| 订单请求响应超时 | 初始 1 秒 | 标记状态未知，不盲目重发 |
| 订单状态未知查询窗口 | 初始 2 秒 | 先通过订单 ID 查询和对账 |
| 自动重新报价次数 | 最多 1 次 | 再失败则拒绝 |
| 最大价格偏离 | 10 bps | 超限拒绝或停止 |
| IOC 部分成交 | 以实际成交量重新计算另一条腿 | 禁止使用原始请求数量 |
| FOK 未完全成交 | 视为未成交 | 不执行另一条腿，除非已存在其他成交 |
| 最小剩余对冲数量 | 必须满足交易所最小交易规则 | 不满足时进入残余风险处理 |
| 反向补偿价格 | 使用新的实时盘口重新计算 | 不允许使用旧价格假设 |
| 连续对冲异常 | 2 次 / 最近 10 次尝试 | 暂停该交易对 |
| 账本余额不一致 | 立即停止该策略 | 对账通过后恢复 |

### 7.1 为什么不能把两腿做成伪原子

CEX 订单与 EVM 交易之间没有共同事务协调器。

因此系统必须将每条腿的真实状态建模为：

- 未提交。
- 已提交。
- 已确认受理。
- 部分成交。
- 完全成交。
- 已撤销。
- 已拒绝。
- 状态未知。

状态未知不是未成交。没有核实订单状态前，禁止自动创建一笔可能重复成交的订单。

### 7.2 部分成交处理

- 只能使用已确认成交数量计算另一条腿。
- 部分成交后重新计算可实现净利润。
- 若剩余数量可以单独成交，则生成新的小额计划并重新风险检查。
- 不满足最小交易规则时，进入残余仓位处置流程。
- 补偿成本计入本次策略实际净利润。

### 7.3 补偿策略

可模拟：

- CEX 未成交时重新报价一次。
- CEX 部分成交后按成交量调整 DEX 数量。
- DEX 回滚后在 CEX 反向成交以解除库存偏移。
- DEX 已完成而 CEX 对冲失败时，按当前 CEX 盘口进行补偿。
- 补偿仍失败时停止对应交易对并提高风险等级。

补偿订单必须有新的价格保护和最大亏损约束，不允许为了“完成对冲”而无限追价。

## 8. 闪电贷风险

| 参数 | 初始值 | 触发处理 |
|---|---|---|
| Provider 白名单 | 必须存在 | 未登记 Provider 拒绝 |
| Provider Chain ID | 必须匹配 | 不匹配拒绝 |
| Token 白名单 | 必须存在 | 未登记资产拒绝 |
| 借款额度 | 不超过可验证可用额度 | 超出拒绝 |
| Fee | 读取真实回调或协议参数 | 不可信则拒绝 |
| Initiator | 必须为本 Executor | 不匹配回滚 |
| 回调调用方 | 必须是登记 Provider | 不匹配回滚 |
| 回调重复执行 | 禁止 | 回滚 |
| Callback Data | 必须匹配计划哈希 | 不匹配回滚 |
| 还款能力 | 本金 + Fee 必须充足 | 不足则回滚 |
| 最低利润 | 扣除本金和 Fee 后仍满足 | 不满足则回滚 |
| 执行中提款 | 禁止 | 拒绝 |
| 无限授权 | 禁止 | 不允许部署 |

闪电贷不是免费的资金。即使一次交易不成功，也应将 Gas 费用计入策略的失败成本。

## 9. Token、稳定币与协议风险

| 风险项 | 初始阈值 / 条件 | 处理方式 |
|---|---|---|
| 稳定币价格偏离 | 0.5% 预警 | 降低评分和规模 |
| 稳定币价格偏离 | 1.0% | 暂停使用该稳定币作为估值基准 |
| Token 暂停 / 冻结 | 检测到相关行为 | 禁止交易 |
| Token 黑名单风险 | 未验证 | 禁止自动交易 |
| Token 可升级代码变化 | 检测到变化 | 暂停并重新审查 |
| Pool 异常状态 | 储备、流动性或状态校验不一致 | 暂停该池 |
| 协议安全事件 | 相关协议出现高风险告警 | 暂停该协议适配器 |
| 未验证 Hook | 未独立测试 | 禁止交易 |
| 价格源不一致 | 超出设定偏差 | 不采用异常报价 |
| Token decimals 不确定 | 无法校验 | 禁止交易 |

价格偏离需要使用可靠的多来源数据，并区分短暂市场波动与真实脱锚。不能只凭单一价格源决定稳定币风险。

## 10. 全局熔断规则

| 触发条件 | 熔断范围 | 初始恢复条件 |
|---|---|---|
| 全局日亏损达到 1% | 全部策略 | 重新核对账本、损失原因和风险配置 |
| 最大回撤达到 5% | 全局暂停 | 风险审查后重新启用 |
| 3 次 / 15 分钟 DEX 回滚 | 相关链或策略 | 至少等待 30 分钟并检查回滚原因 |
| CEX–DEX 连续 2 次对冲异常 / 10 次尝试 | 相关交易对 | 完成订单、库存和账本核对 |
| RPC 持续失联 | 对应链 | 双 RPC 状态重新一致 |
| CEX 盘口不完整 | 对应交易对 | Snapshot 与增量完整同步 |
| 订单状态未知 | 对应账户和交易对 | 查询和对账确认最终订单状态 |
| 库存账本不一致 | 对应策略 | 真实余额或 Paper 账本校准 |
| Token / Pool / Adapter 风险 | 对应资产或协议 | 重新完成风险审查 |
| 合约权限或代码哈希异常 | 合约对应链 | 停止执行并完成安全检查 |

恢复必须记录：

- 熔断原因。
- 触发时间。
- 影响范围。
- 相关交易。
- 账本状态。
- 修复措施。
- 恢复时间。
- 恢复操作者。

## 11. Paper Trading 专属风控统计

第一阶段要求持续统计，不仅关注总利润：

### DEX

- 理论机会数量。
- 精确模拟通过数量。
- 模拟回滚率。
- Gas 成本分布。
- 机会到提交的时间。
- 不同资金规模下的容量。
- 单笔净利润分布。
- 不同链和协议的成功率。

### CEX

- 盘口数据完整率。
- 盘口年龄分布。
- 预期与模拟成交价偏差。
- IOC 成交率。
- FOK 成交率。
- 部分成交率。
- 模拟订单响应时间。
- 手续费和市场冲击。

### CEX–DEX

- 双腿完成率。
- 对冲失败率。
- 部分成交后的平均残余敞口。
- 最大未对冲敞口。
- 平均及 P95 对冲时间。
- 补偿损失分布。
- 库存再平衡成本。
- 不同资金分配比例的净收益。
- 不同成交顺序的风险和收益差异。

### 资金表现

- 已实现净利润。
- 未实现盈亏。
- 总权益曲线。
- 日收益率。
- 最大回撤。
- 夏普或其他收益风险指标。
- 成交容量。
- 资金利用率。
- 策略相关性。
- 最差连续亏损区间。

## 12. 历史审计参数校准

初始默认值不是最终值。参数需要经过以下流程：

1. 历史数据质量审查。
2. 训练区间参数估计。
3. 样本外区间验证。
4. 不同链和交易所分组。
5. 不同资金档位分组。
6. 正常、延迟和压力模型比较。
7. Paper Trading 前向验证。
8. 参数冻结和版本记录。

不可在同一历史样本上反复调整参数后，将最好的一组结果当作真实可复制盈利。

缺少历史 L2 盘口、准确费用或完整区块前状态的样本，必须降低审计等级。

## 13. 风控配置管理

每个参数应存储：

- `parameter_key`
- `scope`
- `strategy_id`
- `chain_id`
- `exchange_id`
- `symbol`
- `value`
- `unit`
- `severity`
- `effective_from`
- `updated_by`
- `version`
- `reason`

支持：

- 全局默认值。
- 策略级覆盖。
- 链级覆盖。
- 交易所级覆盖。
- 交易对级覆盖。

覆盖规则不得突破全局硬限制。

例如：

- 全局最大日亏损为 1%。
- 某策略可以更严格地设为 0.5%。
- 某策略不能自行改为 2%。

## 14. 第一阶段风控验收标准

- 所有硬性限制均在后端执行。
- 每种拒绝原因可查看。
- 每次熔断有对应风险事件。
- 任何订单状态未知均不会触发盲目重复下单。
- CEX 部分成交必须按实际数量重新规划另一条腿。
- 任何 DEX 回滚都计入 Gas。
