## 1. 产品定位与目标

### 1.1 产品定位

面向单操作者的**本地 DEX 原子套利研究、扫描与 Paper Trading 系统**：

- 只读接入公链行情；Binance 公共行情仅作为 DEX 定价与原生资产价格的输入；
- 在图网络上搜索 2–5 跳闭环路线；
- 对每条路线做成本、容量、Gas、风险与压力测算；
- 用 Paper 账本记录“如果执行”的结果；
- 不托管私钥、不签名、不广播真实交易；
- **不再生成 CEX–DEX 双腿对冲机会**。

### 1.2 v2.0 的产品目标

1. **多链可运行**：Arbitrum One 与 Base 各自独立实例运行，共用一套 UI 与代码。
2. **聚焦 DEX 原子套利**：移除 CEX–DEX 扫描链路，减少非原子双腿的状态复杂度。
3. **发现可运营**：数据源、Token 白名单、黑名单、搜索参数均可在 UI 修改并持久化。
4. **路线可解释**：每条路线可展开到跳、池、费用、Gas、容量、逐档净利与拒绝原因。
5. **精度分层**：M1（本地模型）→ M2（REVM/Quoter 复核）→ M2-TX（整笔原子回放）→ M3（压力）。
6. **不制造假机会**：配置错误、价格缺失、池方向错误必须表现为“拒绝/无机会”，不得表现为巨额利润。

### 1.3 非目标（本版本不做）

- 真实资金下单、签名、广播、CEX API Key 下单；
- CEX–DEX 双腿对冲扫描（commit 0720352 已移除）；
- 多链单进程统一扫描（当前为双实例）；
- 6–8 跳搜索（按产品决策只保留 2–5 跳）；
- BSC/Thena 等新增链；
- 对外 SaaS、多租户、账户体系。

## 2. 资金与策略基线

### 2.1 资金基准

| 项目 | 基线 |
|---|---|
| 期初权益 | 5,000 USDC |
| DEX / CEX 分配 | 50% / 50%（保留账本兼容；新机会仅来自 DEX） |
| 研究档位 | 250 / 500 / 1,000 / 2,500 / 5,000 / 7,500 / 10,000 USDC |
| 单机会有效期 | 30 秒 |
| 并发执行上限 | 3 |
| 自动执行 | 关闭（`auto_execute=false`） |
| Paper 执行概率 | 0.5，仅用于模拟 |

### 2.2 策略 A：DEX 原子三角/多跳套利

- 同一链内，从基础资产出发，经过 2–5 跳回到原资产；
- 要求闭环、池不重复、Token 准入通过；
- 输出逐档净利、容量、Gas、风险与生命周期。

### 2.3 策略 B：DEX 跨池套利

- 同一 Token 对在不同 DEX/费率池之间的价差；
- 与策略 A 共用图搜索、成本模型与风控；
- 路线类型包括 `CROSS_POOL`、`TRIANGLE`、`MULTI_HOP`；

> v2.0 策略面只有 A、B 两类（`StrategyType` 仅含 `dex_triple` / `dex_cross`）。CEX–DEX 非原子对冲已整体移除，不再作为策略存在。

### 2.4 CEX 公共行情的角色（非策略，仅数据）

- Binance 公共盘口仍保留，但**降为标价第三票**：
  - 标价主源改为链上最深计价池 spot 价（见 §6.2）；
  - Chainlink 聚合价做交叉校验；
  - Binance 中间价仅在链上/Chainlink 都缺该 Token 时兜底；
  - 盘口深度仍用于数据质量对比与历史 Paper 回归展示。
- **CEX–DEX 非原子套利策略已整体移除**（commit cece2f1）：`StrategyType::CexDex` 枚举、执行链路、风控参数组一并删除；
- `/api/opportunities` 只返回 DEX 原子机会（`dex_triple` / `dex_cross`）；
- `#/scanner-cex` 旧链接重定向到 `#/scanner-dex`。

**为什么不再依赖 CEX 价**：套利价差由链上池状态计算，CEX 价只影响美元换算。
用 CEX 价当标价会引入外部依赖与基差，且 TVL 门槛会随 CEX 行情抖动（实测池数在
23→56→30 之间跳动）。改为链上主源后，三源分歧稳定在 13 bps 以内。

### 2.5 闪电贷边界

- 闪电池仅用于**模拟**与 Paper 计价；
- 真实执行合约未部署、未审计，不在本版本开放；
- 闪电池地址、手续费、Token 支持范围必须显式配置，禁止隐式假设。

## 4. 用户与使用场景

### 4.1 用户角色

- **策略研究者**：调参数、看路线、看逐档净利、判断机会真伪；
- **系统运维者**：看数据源健康、RPC、扫描状态、错误；
- **风控/审计者**：看风险事件、熔断、执行审计与账本。

### 4.2 核心场景

1. 打开“DEX–DEX 搜索”，按链、档位、净利筛选路线；
2. 展开路线，查看逐跳池、费用、Gas、容量、逐档净利；
3. 在“搜索数据源配置”里切换免费/增强模式、填 Key、改轮换策略；
4. 在“池与 Token”里查看池状态、ticks、稳定池、准入状态；
5. 在“Paper 执行/账户/绩效”里查看虚拟成交与盈亏；
6. 在“风控/审计/数据质量”里定位异常。

## 5. 功能需求

### 5.1 多链与实例管理（FR-CHAIN）

- 支持 Arbitrum One（42161）与 Base（8453）；
- 每链一个独立实例：
  - Arbitrum：端口 8791，工作区 `data/`；
  - Base：端口 8792，工作区 `instances/base/data/`；
- 通过 `ARBX_PROFILE` 叠加 `config/<profile>.toml`；
- UI 由同一份构建产物提供，API 以实例端口区分；
- 页面展示链 ID、区块、RPC 健康、池数量；
- **当前不提供**“单进程多链统一扫描”，两个实例各自独立扫描。

### 5.2 数据源与自动发现（FR-DISCOVERY）

- 内置 27 个数据源，分两类：
  - 14 个免费源（GeckoTerminal、DexScreener、DefiLlama、Blockscout、Pyth、Curve、Balancer、公共 RPC、Binance 公共行情、Sourcify 等）；
  - 13 个需 Key 源（CoinGecko、GoPlus、Arbiscan、Alchemy、Infura、QuickNode、Ankr、TheGraph、CoinPaprika、CryptoCompare、Moralis、Covalent 等）。
- UI“搜索数据源配置”支持：
  - 查看/修改启用状态、权重、速率、轮换策略、Key；
  - Key 掩码显示；
  - 一键“免费模式 / 增强模式”预设；
  - 保存到 `data/source_config.json`。
- 规则：
  - 需 Key 的源在无 Key 时强制禁用；
  - 免费模式只启用免费源；
  - 增强模式启用“免费源 + 已配置 Key 的源”。
- 自动发现：
  - 来源：GeckoTerminal / CoinGecko / DexScreener；
  - 仅接受已知协议（Uniswap V3 等），未知协议跳过；
  - TVL 合理性过滤（约 1 万–10 亿美元）；
  - 结果写入 `data/discovered_pools.json`；
  - 新 Token 自动登记为待审/白名单条目，可在 UI 调整；
  - 发现周期默认 1,800 秒，避免免费额度耗尽。

### 5.3 Token 与池管理（FR-POOL）

- Token 字段：符号、地址、精度、准入角色（start/hop/flash）、状态、风险标签；
- 池字段：协议、地址、类型（V2/V3/StableSwap/Weighted）、费率、Token0/1、TVL、区块、状态年龄；
- 支持：
  - 自动发现池合并；
  - 手工额外池配置；
  - 黑名单/暂停；
  - V3 tick 数量展示（`ticks_loaded`）；
  - 稳定池曲线类型展示。
- 池准入：
  - 必须 `verified && execution_allowed`；
  - TVL 门槛、状态年龄门槛；
  - 单池容量占比上限。

### 5.4 搜索配置（FR-SEARCHCFG）

配置入口为页面右上角「搜索配置」按钮，点击从右侧滑出抽屉（可拖拽调宽），
取代此前的内联面板。参数分六组，共 25 项：

| 分组 | 参数 |
|---|---|
| 池与准入 | 池 TVL 门槛、单池深度占比、池状态最大年龄、参与池上限 |
| 规模与跳数 | 单笔下限/上限、最小/最大跳数、投入网格点数、最优点细化迭代 |
| 搜索预算 | 候选路线上限、单轮定价上限、单轮定价预算（ms） |
| 时效与增量 | 机会有效期、报价复用上限、全量重建间隔（区块） |
| 成本与安全垫 | Gas 价格覆盖（0=链上）、优先费、闪电贷费率、延迟预留、MEV 预留、利润折扣 |
| 一致性与压力 | M1/M2 偏差阈值、池状态扰动、压力 Gas 上调 |
| 投入阶梯 | 逗号分隔的金额档位（默认 7 档） |
| Token 白/黑名单 | 增删改与状态切换；需重启后端重建 feed |

- 所有参数带单位与取值校验，越界值不会写入引擎（`SearchParams::apply` 逐项钳制）；
- 旧版配置文件自动升级（缺失字段整组回填默认值），避免 0 值把费率/预算清零；
- Token 符号做 ASCII 校验，拒绝乱码符号（历史发现源遗留问题）；
- 保存到 `data/search_config.json`，下一轮扫描生效，无需重启；
- 抽屉底部提供「重载」（放弃未保存修改）与「保存配置」。

### 5.5 DEX 扫描引擎（FR-SCAN）

- 图构建：Token 为节点、池方向为边；同一链内不重复池；
- DFS 简单环搜索，2–5 跳；
- 路线类型：跨池、三角、多跳；
- 每条路线：
  - 计算容量、投入区间、资金档位；
  - 逐档报价（不是插值）；
  - 输出毛利、显式成本、净利、bps、Gas、容量；
  - 生成生命周期与拒绝原因；
- 增量扫描：
  - 仅对池状态变化/价格变化/过期路线重报价；
  - 全量重建按区块间隔或手动触发；
- 预算：
  - 候选数、访问数、时间片上限；
  - 超限标记 `truncated`，不得静默丢弃。

### 5.6 路线与机会展示（FR-ROUTE）

- 路线列表字段：链、类型、Token 闭环、Pool 路径、跳数、投入、回款、毛利、成本、净利、bps、容量、年龄、生命周期；
- 筛选：链、档位、净利、跳数、类型、状态；
- 路线详情：
  - 资金档位矩阵（档位/投入/回款/毛利/成本/净利/bps）；
  - 逐跳池、协议、费率、价格影响；
  - 报价年龄、区块、机会 ID、生命周期、拒绝原因；
  - M2/M3 证据（如有）。

### 5.7 CEX 公共行情（定价输入，非扫描链路）（FR-MARKET）

- Binance 公共行情：`time/exchangeInfo/depth/bookTicker/price`；
- 盘口引擎：中间价、深度、滑点、数据年龄；
- 用途：**标价第三票/兜底**（主源见 §6.2）、数据质量对比、历史回归；
- **不生成 CEX–DEX 机会**；
- 旧 `#/scanner-cex` 书签自动落到 DEX 搜索页；
- CEX–DEX 执行链路（双腿模拟、部分成交回滚、对账窗口）已随策略一并删除；`/api/paper/hedges` 保留但恒返回空。

### 5.8 Paper Trading（FR-PAPER）

- 虚拟账户、持仓、成交、对冲记录；
- 期初 5,000 USDC，DEX/CEX 各 50%；
- 自动执行关闭；按概率模拟成交；
- 账本、库存、绩效、权益曲线；
- 支持重置（Paper reset）；
- 不产生真实链上交易或 CEX 订单。

### 5.9 风控与熔断（FR-RISK）

- 风险规则目录、参数基线、覆盖项；
- 断路器：日亏损、连续亏损、数据过期、库存不足、模型偏差、滑点超限等；
- 全局暂停/恢复；
- 风险事件持久化与 UI 展示；
- 任何“可执行”机会必须通过风险门禁。

### 5.10 账本与审计（FR-LEDGER）

- 账户类型：DEX/CEX/现金/费用等（CEX 账户保留以兼容历史账本）；

- 历史审计：任务、报告、数据质量、模型等级；

### 5.11 执行合约与原子回放（FR-EXEC）

### 5.12 系统与数据源页面（FR-SYS）

- 能力矩阵、执行合约、风控、审计入口。

## 6. 关键业务规则

### 6.1 机会生命周期

`DISCOVERED → QUOTED → RISK_CHECKED → ACTIONABLE / WATCH / REJECTED → EXPIRED / EXECUTED`

- 过期时间默认 30 秒；
- 过期后不得执行；
- 拒绝必须带原因码。

### 6.2 成本与净利（双口径 + 标价来源）

```
net_token = 回款 − 投入                      # 起始资产口径，纯链上
net_usd   = 净利 = 回款 − 投入 − 显式成本     # 美元口径，含全部成本
显式成本   = Gas + 优先费 + 闪贷费 + 延迟/MEV 储备 + 其他
```

- 两个口径同时展示：USD 主行 + 起始资产副行。起始资产为稳定币时，两者差额即执行成本，
  可据此判断亏损来自「价差不足」还是「成本过重」；
- 可执行判定仍以 `net_usd` 为准（成本必须以美元计价）；
- Gas 以链上 `eth_gasPrice`/basefee 与原生币价格计算；
- 闪贷费必须来自配置/协议，禁止硬编码为 0；
- 逐档报价必须使用同一成本口径。

**标价（mark price）规则** —— 只用于美元换算，不参与 AMM 定价：

| 层 | 来源 | 说明 |
|---|---|---|
| L1 主源 | 链上最深计价池 spot 价 | 与 USDC/USDT 配对、按 TVL 取最深，同链原子一致 |
| L2 校验 | Chainlink 聚合价 | ETH/BTC/LINK/ARB/USDC，校验 `updatedAt` 新鲜度 |
| L3 兜底 | Binance 中间价 | 仅前两层缺失该 Token 时生效 |

- 稳定币（USDC/USDT/DAI）固定 1 美元；
- 三源取中位数作最终标价，并记录与中位数的最大偏差；
- 偏差 > 50 bps 视为分歧，相关机会降级为「观察」（见 §6.3）；
- 白名单外 Token（发现源带入的未登记/乱码符号）一律剔除，不进入标价表。

### 6.3 风险门禁

- 数据年龄超限 → 拒绝；
- 池 TVL/容量不足 → 拒绝；
- 风险分数/评分不足 → 观察或拒绝；
- 模型偏差超阈值 → 拒绝；
- **标价分歧超阈值（> 50 bps）→ 降级为观察**；
- 熔断/暂停 → 全部拒绝。

### 6.4 真实性与安全

- 不展示无法由当前数据解释的利润；
- 配置错误必须可被“容量/价格/准入”检查捕获；
- 所有 Key 只存本地 JSON，UI 掩码；
- 日志不得输出完整 Key。

## 9. 已知限制与风险

1. **公共 RPC 不稳定**：429、批大小限制、连接重置会导致 feed 超时；生产化需专用 RPC。
2. **无真实盈利机会**：截至最后验收，两链正收益路线为 0；系统应按 0 展示，不得制造机会。
3. **配置敏感**：池 token 顺序、cbBTC 价格键、稳定池曲线类型都会显著影响结果，需有回归测试与诊断日志。
4. **原子执行仅为模拟**：executor 未部署、未审计，不能用于真实资金。
5. **Aerodrome 波动池**：报价按 x*y=k；稳定池按固定曲线；两者不能混用。
6. **M2 限制**：QuoterV2 仅 V3；M2-TX 仅 V3/Uniswap V2 Router；闪电池映射有限。
7. **免费数据额度**：发现周期与页数受免费额度约束。
8. **CEX–DEX 已移除**：仅保留 Binance 公共行情做定价输入；旧策略页/历史记录不等于新扫描能力。
