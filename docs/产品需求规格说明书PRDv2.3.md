## 2. v2.3 目标（R1–R6）

### R1 归档回放（P0，可切换）
- **方式**：复用 RPC 的 free/paid 模式，新增 `archive_endpoints`；仅当配置了归档端点才启用按区块重建。
- **能力**：按历史区块 `eth_call`（`getReserves` / `slot0+liquidity`）重建池状态 → 重算路线净利 → 与记录值对比。
- **门控**：无归档端点时，接口返回 `UNAVAILABLE` 并保留现有 `RECORDED_QUOTE` 复算，不降级为伪数据。
- **验收**：归档端点配置后，窗口内可复算且误差 ≤ 记录容差；窗口外 `OUT_OF_WINDOW`。

### R2 实盘就绪门（P0，不签名）
- **方式**：`live_approval` 配置 + 审批记录表；干跑 harness 走完整构造/校验路径但不签名、不广播。
- **能力**：readiness 扩展为逐项证据链（合约字节码哈希、风控参数快照、模拟覆盖率、审计样本量）。
- **验收**：`ready` 仍恒为 false；干跑可输出完整调用计划与预期 Gas。

### R3 V3 跨 tick（P1，门控）
- **方式**：`tick_word_radius > 0` 时加载 top TVL 池的 tick 位图，带超时与失败降级。
- **验收**：加载不超时；跨 tick 报价与单区间报价并列展示，标注模型等级。

### R4 竞争者采集增强（P1）
- **方式**：多窗口回补（默认 2000 块，单次 ≤50 块）、429 退避；聚类加入竞价习惯（Priority Fee 分布）与活跃时段。
- **验收**：近 2000 块可完整回补；聚类输出可信度与依据。

### R5 竞争模拟入账（P1）
- **方式**：FILLED 走 Paper 账本记账，MISSED 计 Gas 失败成本；双链账户隔离。
- **验收**：`equity − start_equity == 净利` 仍成立；失败成本可追溯。

### R6 前端（P1，9 项）
- **现状**：v2.2 的 7 项前端任务只完成 1 项（竞争页），4 项未做、2 项为替代。
- **方式**：补齐 Dashboard 竞争面板、机会生命周期页、审计页回放、Paper 页三态归因、
  竞争驾驶舱、指标页扩展；**移除演示数据兜底**；清理 CEX–DEX 过期文案。
- **验收**：全部数据来自真实 API；后端不可达时显示空状态与原因；无演示数据冒充。

## 4. 非目标

- 不做 6–8 跳、BSC/Thena、CEX–DEX 非原子策略、链上盲目探测；
- 不开放实盘签名与广播（R2 也只做干跑）；
- 不因缺少资源下调风控门槛或伪造数据。

## 5. 验收标准（A1–A6）

| 编号 | 验收项 | 判定 |
|---|---|---|
| A1 | 归档回放 | 配置归档端点后窗口内可复算；未配置返回 UNAVAILABLE |
| A2 | 实盘就绪门 | ready 恒 false；干跑输出完整计划；审批记录可追溯 |
| A3 | 跨 tick | 加载不超时；报价与单区间并列且标注等级 |
| A4 | 竞争者采集 | 近 2000 块可回补；聚类有可信度 |
| A5 | 模拟入账 | 权益恒等式成立；失败成本可追溯 |
| A6 | 前端驾驶舱 | 数据全部来自真实 API；无演示数据 |

## 6. 风险

1. 归档节点成本 → 默认关闭，不影响现有功能；
2. 跨 tick 加载拖慢扫描 → 超时 + top 池限制 + 失败降级；
3. 聚类误判 → 标注概率识别，不宣称机器人身份；
4. 干跑与真实执行差异 → 明确标注"未签名/未广播"，不可当成实盘验证。
