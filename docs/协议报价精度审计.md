# 协议报价精度审计（V22-301）

> 目的：确认 V2 / V3 / StableSwap / Weighted 四类 AMM 的报价实现与测试覆盖，明确已知限制。
> 依据：PRD v2.2 §7.2、TDD v2.0 §4；实现位于 `backend/src/dex/math.rs`、`dex/pool.rs`。

## 1. 覆盖矩阵

| 协议 | 实现函数 | 关键语义 | 测试覆盖 | 已知限制 |
|---|---|---|---|---|
| Uniswap V2 | `math::v2_amount_out` / `v2_amount_in` / `v2_spot_price` | 恒定乘积、含手续费、整数精度 | `dex/math.rs` 单测（含边界：amount=0、储备为 0、超额输出） | 无 |
| Uniswap V3 | `math::v3_amount_out` / `v3_amount_in`（单区间） | `slot0 + liquidity` 单活跃区间报价 | 同上 | **跨 tick 未启用**（`tick_word_radius=0`），属 M1 近似 |
| StableSwap | `math::stableswap_amount_out` | 不变式求解 + 迭代收敛 | 同上（含收敛失败回退） | 强偏斜时迭代次数受限，结果标注近似 |
| Weighted AMM | `math::weighted_amount_out` / `weighted_spot_price` | `w_in/w_out` 加权恒定乘积 | 同上 | 无 |
| Aerodrome 波动池 | 复用 V2 恒定乘积 | `fee_bps` 来自池配置 | `dex/pool.rs` 分派测试 | 稳定池曲线未实现（不接入） |

## 2. 方向与单位约定

- `token_in == pool.token0` → `zero_for_one`；反方向必须得到不同报价（`pool.rs` 测试覆盖）。
- 所有储备与 V3 `sqrtPriceX96` 使用池内**原始单位**；人类可读价格由调用方按 decimals 换算。
- 报价失败返回 `QuoteError`，不静默跳过；`amount_out = 0` 属可成交性判定，由上层拒绝。

## 3. 与成本口径的关系

- AMM 手续费与滑点已内含在 `amount_out` 中，**成本模型不得重复扣减**（PRD §8.2）；
- `strategy/cost.rs` 的 `CostParts` 只累计真实现金成本（Gas/闪电贷/优先费/准备金）。

## 4. 结论

四类协议的报价实现与单元测试均存在且通过；**唯一未覆盖能力是 V3 跨 tick 位图**。
该项在 v2.2 中标记为受限，替代方案见 PRD v2.3 §1（配置门控，付费全节点就绪后开启）。

## 5. 审计方式（可复现）

```text
cargo test --lib --tests dex::math dex::pool
```

未通过任何一项即视为报价精度回归。
